# Дашборд таймлайнів PR (MPNP → eCoPR)

Два файли:
- `Code.gs` — бекенд: Google Таблиця + Apps Script (безкоштовно, зберігає кейси).
- `index.html` — сам дашборд (форма, фільтри, статистика). Хоститься на GitHub Pages (безкоштовно).

Поки в `index.html` не вставлено `API_URL`, сторінка працює в демо-режимі з прикладом даних.

## Крок 1. Бекенд (Google Таблиця), ~5 хв

1. Створіть нову Google Таблицю (наприклад, «PR timelines DB»). **Не діліться нею публічно**: там зберігаються коди редагування.
2. Меню **Розширення → Apps Script**.
3. Видаліть усе з `Code.gs` і вставте вміст файлу `Code.gs` звідси. Збережіть (💾).
4. **Deploy → New deployment** → шестерня → **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
5. Натисніть **Deploy**, дозвольте доступ (Google попередить, що застосунок не перевірений: *Advanced → Go to … (unsafe)*, це ваш власний скрипт).
6. Скопіюйте **Web app URL** (закінчується на `/exec`).

Аркуш `cases` створиться автоматично при першому запиті.

Перевірка: відкрийте URL у браузері, маєте побачити `{"ok":true,"cases":[]}`.

## Крок 2. Підключити дашборд

У `index.html` знайдіть рядок

```js
const API_URL = '';
```

і вставте свій URL між лапками.

## Крок 3. Викласти онлайн (GitHub Pages)

1. На github.com → **New repository**, наприклад `pr-timelines`, **Public**.
2. **Add file → Upload files** → завантажте `index.html` → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save.
4. Через 1–2 хв сайт буде за адресою `https://<ваш-логін>.github.io/pr-timelines/`.

Альтернатива без GitHub: https://app.netlify.com/drop, перетягніть папку з `index.html`.

## Як це працює для учасників

- «Додати свій кейс»: людина заповнює форму і отримує **код редагування** (на зразок `a1b2c3d4-…`).
- На тому ж пристрої біля її кейсу з'являється кнопка «Редагувати». На іншому пристрої треба натиснути «Редагувати за кодом».
- Так людина дописує нові дати (AOR, PAL, eCoPR), коли вони з'являються.

## Модерація

- Усі кейси лежать у Google Таблиці: спам або помилкові рядки можна просто видалити чи виправити там.
- Захист від ботів: приховане поле-пастка і ліміт 30 нових кейсів за 10 хвилин.

## Оновлення бекенду

Якщо змінюєте `Code.gs`: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. URL при цьому не змінюється.
